# เซิร์ฟเวอร์ MCP ในเครื่อง (ฉบับภาษาไทย)

ให้แอป AI บนคอมพิวเตอร์ (Claude Code, Claude Desktop, Codex CLI, Cursor ฯลฯ) **แปลง PDF หรือรูปภาพเป็นใบงานโต้ตอบ** หรือสร้างใบงานใหม่จากหัวข้อ โดย AI จะวางช่องคำตอบ ตรวจหน้าตัวอย่างจริง แล้วบันทึกไฟล์ `.owpkg`

ใบงานที่ได้เป็นภาษาไทย (ฟอนต์ Sarabun, ถูก/ผิด) และ **ส่งคะแนนเข้าบัญชีครูบนเว็บอัตโนมัติ** เมื่อตั้งค่ารหัสครูไว้

> ถ้าใช้ Claude.ai บนเว็บหรือแอป Claude และไม่ต้องแปลง PDF ให้ใช้ **MCP บนเว็บ** แทน (ไม่ต้องติดตั้ง): หน้า «ห้องครู» → เชื่อมต่อ AI (MCP)

## สิ่งที่ต้องมี

- Node.js 18 ขึ้นไป
- Google Chrome, Chromium หรือ Microsoft Edge (ใช้แสดงหน้าตัวอย่างให้ AI ตรวจ)

## ติดตั้ง (ให้ AI ทำให้)

1. เปิดหน้า «ห้องครู» บนเว็บ → ส่วน **MCP ในเครื่อง** → กด **คัดลอกคำสั่งติดตั้ง** (มีรหัสครูของคุณอยู่แล้ว)
2. วางในแชตของแอป AI บนคอมพิวเตอร์ AI จะโหลดโปรเจกต์ ลงทะเบียน MCP และตั้งค่าให้

### ถ้าติดตั้งเอง

```bash
git clone https://github.com/FIFTEEN012/thai-worksheets.git
```

ลงทะเบียนในไคลเอนต์ MCP: transport **stdio**, ชื่อ **thai-worksheets**, คำสั่ง **node**, อาร์กิวเมนต์ = path เต็มของ `thai-worksheets/mcp/server.js` และตัวแปรสภาพแวดล้อม:

| ตัวแปร | ค่า |
|---|---|
| `OWS_TEACHER_CODE` | รหัสส่งคะแนนของคุณ (ดูได้ในคำสั่งติดตั้งที่หน้า «ห้องครู») |
| `OWS_SITE` | `https://thai-worksheets.vercel.app` |

ตัวอย่างสำหรับ Claude Code:

```bash
claude mcp add thai-worksheets -e OWS_TEACHER_CODE=รหัสของคุณ -e OWS_SITE=https://thai-worksheets.vercel.app -- node /path/to/thai-worksheets/mcp/server.js
```

> ต้อง clone ทั้งโปรเจกต์ (ไม่ใช่เฉพาะโฟลเดอร์ `mcp`) เพราะหน้าตัวอย่างใช้โค้ดของเว็บจากโฟลเดอร์ `js/`, `css/`, `fonts/`

## ตัวอย่างคำสั่ง

- «แปลง PDF นี้เป็นใบงานโต้ตอบ: C:\Users\ครู\Downloads\ใบงานบทที่3.pdf ให้นักเรียนเลือกห้อง ม.2/1 ม.2/2»
- «สร้างใบงาน 10 ข้อ เรื่องเซลล์ ม.1 แบบเลือกตอบ ถูกผิด และเติมคำ บันทึกไว้ที่เดสก์ท็อป»
- «ข้อ 5 เปลี่ยนเป็นแบบเลือกตอบหลายข้อ»

จากนั้นอัปโหลดไฟล์ `.owpkg` ขึ้น Google Drive แล้วสร้างลิงก์นักเรียนในหน้าแรกของเว็บ หรือเปิดในตัวแก้ไขเพื่อปรับเพิ่ม
