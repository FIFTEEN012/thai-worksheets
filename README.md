# OpenWorksheets ภาษาไทย · ระบบทำใบงานออนไลน์ตรวจอัตโนมัติ

เว็บแอปสำหรับครู เปลี่ยน PDF หรือรูปภาพให้เป็นใบงานออนไลน์ที่ตรวจคำตอบอัตโนมัติ วางช่องคำตอบลงบนเอกสาร กำหนดคำตอบที่ถูกและคะแนน แล้วแชร์ลิงก์หรือคิวอาร์โค้ดให้นักเรียนทำในเบราว์เซอร์ หรือจะเริ่มจากหน้าว่างก็ได้

ไม่ต้องมีเซิร์ฟเวอร์ ไม่ต้องสมัครบัญชี และทุกอย่างทำงานในเบราว์เซอร์

ดัดแปลงจาก [OpenWorksheets](https://github.com/openworksheets/openworksheets.github.io) (AGPL-3.0) โดยใช้ [REA](https://github.com/morluto/rea) วิเคราะห์โครงสร้างแอปก่อนแก้ไข ดูผลวิเคราะห์ได้ที่ [docs/rea-analysis-th.md](docs/rea-analysis-th.md)

## สิ่งที่เพิ่มหรือเปลี่ยนในฉบับภาษาไทย

- **อินเทอร์เฟซภาษาไทยทั้งหมด** (1,005 ข้อความ) ใน [js/i18n-th.js](js/i18n-th.js) และตั้งภาษาไทยเป็นค่าเริ่มต้น เปลี่ยนเป็นภาษาอื่นได้จากเมนูเลือกภาษา
- **ฟอนต์ไทย** Sarabun (ค่าเริ่มต้น) และ Noto Sans Thai Looped (ตัวมีหัว เหมาะกับเด็กเล็ก) เก็บไว้ในโฟลเดอร์ `fonts/` ใช้แบบออฟไลน์ได้ และฟอนต์เดิมทุกตัวจะใช้ Sarabun แสดงอักษรไทยแทนให้อัตโนมัติ
- **การตรวจคำตอบภาษาไทย**: ไม่สนใจการเว้นวรรคระหว่างคำไทย («กลางวัน กลางคืน» = «กลางวันกลางคืน») ตัดอักขระที่มองไม่เห็นซึ่งมักติดมาตอนคัดลอก และถือว่า «ํา» เท่ากับ «ำ»
- **นับคำภาษาไทย** ในช่องคำตอบยาวด้วยการตัดคำของเบราว์เซอร์ (`Intl.Segmenter`) แทนการนับช่องว่าง
- **ค่าเริ่มต้นของช่องเป็นภาษาไทย** เช่น ถูก/ผิด, ตัวเลือก 1, ตารางตัวอย่าง
- **ใบงานตัวอย่างภาษาไทย** เรื่องระบบสุริยะ ป.6: [ejemplos/thai-solar-system.owpkg](ejemplos/thai-solar-system.owpkg)
- พรอมต์สร้างใบงานด้วย AI เป็นภาษาไทย พร้อมตัวอย่างภาษาไทย

## ทดลองใช้งานในเครื่อง

ต้องเปิดผ่านเว็บเซิร์ฟเวอร์ (เปิดไฟล์ `index.html` ตรง ๆ ไม่ได้ เพราะเป็น ES module)

```bash
npx -y http-server@14.1.1 -p 8765 -c-1 .
```

แล้วเปิด <http://localhost:8765>

- หน้าแรก: `index.html`
- ตัวแก้ไขใบงาน (ครู): `editor.html`
- ทำใบงาน (นักเรียน): `alumno.html?url=<ลิงก์ไฟล์ .owpkg>`
- ตรวจงานที่ส่ง (ครู): `entregas.html`

## ขั้นตอนใช้งานจริง

1. ครูเปิด **ตัวแก้ไข** → อัปโหลด PDF/รูปภาพ หรือเริ่มหน้าว่าง → ลากวางช่องคำตอบ → กำหนดเฉลยและคะแนน
2. **ไฟล์ → บันทึกใบงาน (.owpkg)** แล้วอัปโหลดขึ้น Google Drive ตั้งค่าแชร์เป็น «ทุกคนที่มีลิงก์»
3. วางลิงก์ Drive ในหน้าแรก → **สร้างลิงก์** → ส่งลิงก์/คิวอาร์โค้ดให้นักเรียน
4. นักเรียนกรอกชื่อ ทำใบงาน กด **ส่งและตรวจคำตอบ** แล้วส่งไฟล์ `.owsub` หรือลิงก์กลับมา
5. ครูเปิดงานที่ส่งในหน้า **ตรวจงานที่ส่ง** ดูคะแนนทั้งห้อง และส่งออกเป็น CSV ได้

## นำขึ้นเว็บ (GitHub Pages)

เป็นไฟล์ static ทั้งหมด อัปโหลดทั้งโฟลเดอร์ขึ้น GitHub Pages, Netlify หรือโฮสต์ใดก็ได้

ข้อควรทราบ: การดาวน์โหลดใบงานจาก Google Drive ใช้ Google Apps Script ของผู้พัฒนาต้นฉบับ ซึ่ง `config.js` จะปิดไว้อัตโนมัติเมื่อแอปไม่ได้รันบนโดเมนต้นฉบับหรือ localhost ถ้าจะเปิดให้คนอื่นใช้ ให้ติดตั้ง Apps Script ของตัวเองตาม [gas/README.th.md](gas/README.th.md) แล้วใส่ URL ใน `config.js` หากไม่ตั้งค่า ระบบจะใช้ CORS proxy สาธารณะแทน ซึ่งเชื่อถือได้น้อยกว่า

## ไฟล์ที่แก้จากต้นฉบับ

| ไฟล์ | การเปลี่ยนแปลง |
|---|---|
| `js/i18n-th.js` | ใหม่: ข้อความภาษาไทยทั้งหมด |
| `js/i18n.js` | เพิ่มภาษา `th` เป็นค่าเริ่มต้น เมื่อไม่มีข้อความไทยจะใช้ข้อความภาษาอังกฤษแทน |
| `js/util.js` | ปรับการเทียบคำตอบให้รองรับภาษาไทย |
| `js/render.js` | นับคำภาษาไทยด้วย `Intl.Segmenter` |
| `js/fonts.js`, `css/app.css`, `fonts/` | เพิ่มฟอนต์ Sarabun และ Noto Sans Thai Looped |
| `js/fieldtypes.js`, `js/editor.js`, `js/aiimport.js`, `js/grading.js` | ค่าเริ่มต้นของช่องเป็นภาษาไทย |
| `js/aiui.js`, `js/index.js`, `js/theme.js`, `*.html` | ตัวเลือกภาษาไทย ใบงานตัวอย่างไทย และข้อความที่ฝังใน HTML |
| `ejemplos/thai-solar-system.owpkg` | ใหม่: ใบงานตัวอย่างภาษาไทย |
