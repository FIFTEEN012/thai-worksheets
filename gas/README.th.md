# ติดตั้ง Google Apps Script (ฉบับภาษาไทย)

`Code.gs` ทำหน้าที่สองอย่าง:

1. **ช่วยดาวน์โหลดใบงานจาก Google Drive** (Drive ไม่อนุญาตให้เว็บอื่นดาวน์โหลดไฟล์ตรง ๆ)
2. **สร้างลิงก์แบบสั้น** สำหรับแชร์ใบงานให้นักเรียน

สคริปต์ทำงานในบัญชี Google ของคุณเองและใช้โควตาของบัญชีคุณ ไม่มีค่าใช้จ่าย

## ขั้นตอน (ประมาณ 10 นาที)

1. ไปที่ <https://script.google.com> แล้วเข้าสู่ระบบด้วยบัญชี Google ที่จะใช้ (แนะนำบัญชีของโรงเรียนหรือบัญชีที่ใช้เก็บใบงาน)
2. กด **โปรเจ็กต์ใหม่ (New project)** แล้วตั้งชื่อ เช่น `thai-worksheets-proxy`
3. ลบโค้ดตัวอย่างในไฟล์ `Code.gs` ออกทั้งหมด แล้ววางเนื้อหาทั้งไฟล์จาก [gas/Code.gs](Code.gs) (เปิดไฟล์ใน GitHub กดปุ่ม **Copy raw file**)
4. กด **บันทึก** (Ctrl+S)
5. ที่แถบด้านบน เลือกฟังก์ชัน **`authorize`** แล้วกด **เรียกใช้ (Run)**
   - Google จะขอสิทธิ์เข้าถึง Drive และการเชื่อมต่อภายนอก กด **ตรวจสอบสิทธิ์ (Review permissions)** แล้วเลือกบัญชี
   - ถ้าเจอหน้า **«Google ยังไม่ได้ยืนยันแอปนี้»** ให้กด **ขั้นสูง (Advanced)** → **ไปที่ thai-worksheets-proxy (ไม่ปลอดภัย)** หน้านี้ขึ้นได้ปกติ เพราะเป็นสคริปต์ที่คุณสร้างเอง
   - กด **อนุญาต (Allow)**
6. กด **ทำให้ใช้งานได้ (Deploy)** → **การทำให้ใช้งานได้รายการใหม่ (New deployment)**
   - กดรูปเฟือง ⚙ แล้วเลือก **เว็บแอป (Web app)**
   - **เรียกใช้ในฐานะ (Execute as):** ฉัน (บัญชีของคุณ)
   - **ผู้ที่มีสิทธิ์เข้าถึง (Who has access):** ทุกคน (Anyone)
7. กด **ทำให้ใช้งานได้ (Deploy)** แล้วคัดลอก **URL ของเว็บแอป** ที่ลงท้ายด้วย `/exec`
8. เปิด [config.js](../config.js) แล้ววาง URL ที่บรรทัด `gasUrl`:

   ```js
   gasUrl: 'https://script.google.com/macros/s/xxxxxxxx/exec',
   ```

9. Commit แล้ว push ขึ้น GitHub ภายในประมาณ 1 นาที เว็บจะอัปเดต และแถบแจ้งเตือนสีแดงด้านล่างจะหายไป

## ทดสอบว่าใช้ได้

เปิด URL `/exec` ในเบราว์เซอร์ ถ้าใช้ได้จะเห็นหน้าข้อความของสคริปต์ จากนั้นในหน้าแรกของเว็บ ให้วางลิงก์ Google Drive ของไฟล์ `.owpkg` (ต้องแชร์แบบ «ทุกคนที่มีลิงก์») แล้วกด **สร้างลิงก์** ถ้าได้ลิงก์สำหรับนักเรียนกลับมา แสดงว่าตั้งค่าถูกต้อง

## ข้อควรระวัง

- สคริปต์จะสร้างโฟลเดอร์ `ZipWebSites` และไฟล์ `shortlinks.json` ใน Drive ของคุณ **อย่าลบ ย้าย หรือเปลี่ยนชื่อ** เพราะลิงก์แบบสั้นที่สร้างไว้ทั้งหมดจะใช้ไม่ได้
- ถ้าแก้ `Code.gs` ภายหลัง ให้ไปที่ **ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชันใหม่** โดย URL `/exec` จะยังเหมือนเดิม
- ใน `config.js` ฉบับภาษาไทย ระบบจะใช้ URL ที่คุณใส่ได้กับทุกโดเมน และจะไม่ใช้ URL ของผู้พัฒนาต้นฉบับ
