# ติดตั้ง Google Apps Script (ฉบับภาษาไทย)

`Code.gs` ทำหน้าที่สองอย่าง:

1. **ช่วยดาวน์โหลดใบงานจาก Google Drive** (Drive ไม่อนุญาตให้เว็บอื่นดาวน์โหลดไฟล์ตรง ๆ)
2. **สร้างลิงก์แบบสั้น** สำหรับแชร์ใบงานให้นักเรียน

สคริปต์ทำงานในบัญชี Google ของคุณเองและใช้โควตาของบัญชีคุณ ไม่มีค่าใช้จ่าย

## ขั้นตอน (ประมาณ 10 นาที)

1. ไปที่ <https://script.google.com> แล้วเข้าสู่ระบบด้วยบัญชี Google ที่จะใช้ (แนะนำบัญชีของโรงเรียนหรือบัญชีที่ใช้เก็บใบงาน)
2. กด **โปรเจ็กต์ใหม่ (New project)** แล้วตั้งชื่อ เช่น `thai-worksheets-proxy`
3. ลบโค้ดตัวอย่างในไฟล์ `Code.gs` ออกทั้งหมด แล้ววางเนื้อหาทั้งไฟล์จาก [gas/Code.gs](Code.gs) (เปิดไฟล์ใน GitHub กดปุ่ม **Copy raw file**)
4. กด **บันทึก** (Ctrl+S)
5. ที่แถบด้านบน เลือกฟังก์ชัน **`authorize`** แล้วกด **เรียกใช้ (Run)**
   - Google จะขอสิทธิ์เข้าถึง Drive และการเชื่อมต่อภายนอก กด **ตรวจสอบสิทธิ์ (Review permissions)** แล้วเลือกบัญชี
   - ถ้าเจอหน้า **«Google ยังไม่ได้ยืนยันแอปนี้»** ให้กด **ขั้นสูง (Advanced)** → **ไปที่ thai-worksheets-proxy (ไม่ปลอดภัย)** หน้านี้ขึ้นได้ปกติ เพราะเป็นสคริปต์ที่คุณสร้างเอง
   - กด **อนุญาต (Allow)**
6. กด **ทำให้ใช้งานได้ (Deploy)** → **การทำให้ใช้งานได้รายการใหม่ (New deployment)**
   - กดรูปเฟือง ⚙ แล้วเลือก **เว็บแอป (Web app)**
   - **เรียกใช้ในฐานะ (Execute as):** ฉัน (บัญชีของคุณ)
   - **ผู้ที่มีสิทธิ์เข้าถึง (Who has access):** ทุกคน (Anyone)
7. กด **ทำให้ใช้งานได้ (Deploy)** แล้วคัดลอก **URL ของเว็บแอป** ที่ลงท้ายด้วย `/exec`
8. เปิด [config.js](../config.js) แล้ววาง URL ที่บรรทัด `gasUrl`:

   ```js
   gasUrl: 'https://script.google.com/macros/s/xxxxxxxx/exec',
   ```

9. Commit แล้ว push ขึ้น GitHub ภายในประมาณ 1 นาที เว็บจะอัปเดต และแถบแจ้งเตือนสีแดงด้านล่างจะหายไป

## ทดสอบว่าใช้ได้

เปิด URL `/exec` ในเบราว์เซอร์ ถ้าใช้ได้จะเห็นหน้าข้อความของสคริปต์ จากนั้นในหน้าแรกของเว็บ ให้วางลิงก์ Google Drive ของไฟล์ `.owpkg` (ต้องแชร์แบบ «ทุกคนที่มีลิงก์») แล้วกด **สร้างลิงก์** ถ้าได้ลิงก์สำหรับนักเรียนกลับมา แสดงว่าตั้งค่าถูกต้อง

## ข้อควรระวัง

- สคริปต์จะสร้างโฟลเดอร์ `ZipWebSites` และไฟล์ `shortlinks.json` ใน Drive ของคุณ **อย่าลบ ย้าย หรือเปลี่ยนชื่อ** เพราะลิงก์แบบสั้นที่สร้างไว้ทั้งหมดจะใช้ไม่ได้
- ถ้าแก้ `Code.gs` ภายหลัง ให้ไปที่ **ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชันใหม่** โดย URL `/exec` จะยังเหมือนเดิม
- ใน `config.js` ฉบับภาษาไทย ระบบจะใช้ URL ที่คุณใส่ได้กับทุกโดเมน และจะไม่ใช้ URL ของผู้พัฒนาต้นฉบับ

# เปิดใช้ระบบส่งคะแนนออนไลน์ (นักเรียนกดส่ง → คะแนนเข้า Google Sheets)

ทำครั้งเดียว ประมาณ 5 นาที ถ้าเคยติดตั้ง Apps Script ตามขั้นตอนด้านบนแล้ว ให้ทำต่อจากนี้ได้เลย

## 1. อัปเดตโค้ด Apps Script

1. เปิดโปรเจ็กต์เดิมที่ <https://script.google.com>
2. ลบโค้ดเดิมในไฟล์ `Code.gs` ทั้งหมด แล้ววางโค้ดใหม่จาก [gas/Code.gs](Code.gs) (กด **Copy raw file**) จากนั้นกด Ctrl+S
3. ที่แถบด้านบน เลือกฟังก์ชัน **`setupResults`** แล้วกด **เรียกใช้ (Run)**
   - Google จะขอสิทธิ์เพิ่มเพื่อจัดการ Google Sheets ให้กด **ตรวจสอบสิทธิ์ (Review permissions)** → **ขั้นสูง (Advanced)** → **ไปที่ … (ไม่ปลอดภัย)** → **อนุญาต (Allow)**
4. ดูที่ **บันทึกการดำเนินการ (Execution log)** ด้านล่าง จะเห็น 2 บรรทัด:
   - `สเปรดชีตคะแนน: https://docs.google.com/…` คือไฟล์ Google Sheets ที่เก็บคะแนน (อยู่ใน Drive ของคุณ)
   - `รหัสครู: xxxxxxxxxx` **จดรหัสนี้ไว้** ใช้เข้าหน้าดูคะแนน และอย่าให้นักเรียนเห็น
5. กด **ทำให้ใช้งานได้ (Deploy)** → **จัดการการทำให้ใช้งานได้ (Manage deployments)** → กดรูปดินสอ ✏️ → ช่อง **เวอร์ชัน** เลือก **เวอร์ชันใหม่ (New version)** → **ทำให้ใช้งานได้ (Deploy)**
   - URL `/exec` ยังเหมือนเดิม ไม่ต้องแก้ `config.js`
   - **ถ้าข้ามขั้นนี้ ระบบจะยังใช้โค้ดเก่าและรับคะแนนไม่ได้**

## 2. เปิดในใบงาน

1. เปิดใบงานในตัวแก้ไข → **ตั้งค่า** → แท็บ **การตรวจ**
2. ติ๊ก **ส่งคะแนนให้ครูอัตโนมัติเมื่อนักเรียนกดส่ง**
3. ใส่ **รายชื่อห้องเรียน** บรรทัดละหนึ่งห้อง เช่น `ม.1/1` `ม.1/2` นักเรียนจะต้องเลือกห้องจากรายการนี้
4. กด **บันทึก** → **ไฟล์ → บันทึกใบงาน (.owpkg)** → อัปโหลดขึ้น Drive และสร้างลิงก์ให้นักเรียนตามปกติ

## 3. ดูคะแนน

เปิด <https://fifteen012.github.io/thai-worksheets/resultados.html> (หรือปุ่ม **ดูคะแนน** ในหน้าแรก) ใส่รหัสครู แล้วเลือกใบงานและห้องเรียน

- ดูคะแนนเฉลี่ย สูงสุด ต่ำสุด จำนวนที่ผ่าน และสรุปแยกตามห้อง
- คลิกชื่อนักเรียนเพื่อดูคำตอบรายข้อ
- **ส่งออก CSV** เปิดใน Excel ได้ (ภาษาไทยแสดงถูกต้อง) หรือกด **เปิดใน Google Sheets**
- ถ้านักเรียนทำหลายครั้ง จะแสดงเฉพาะครั้งล่าสุดเป็นค่าเริ่มต้น เอาเครื่องหมายออกเพื่อดูทุกครั้ง

## ข้อควรรู้

- **ถ้าส่งไม่สำเร็จ** (เช่น อินเทอร์เน็ตหลุด) นักเรียนจะเห็นปุ่ม **ลองส่งใหม่** และยังดาวน์โหลดไฟล์งานที่ส่งไปให้ครูได้เหมือนเดิม
- คะแนนจะไม่ถูกส่งในโหมด **ดูตัวอย่าง** ของครู
- ไฟล์เสียงที่นักเรียนบันทึกจะไม่ถูกส่งไปใน Sheets (ไฟล์ใหญ่เกิน) ถ้าใบงานมีการบันทึกเสียง ให้นักเรียนดาวน์โหลดไฟล์งานที่ส่งด้วย
- **ใครที่รู้ URL `/exec` ก็ส่งคะแนนปลอมเข้ามาได้** (ระบบไม่มีการเข้าสู่ระบบของนักเรียน) ถ้าคะแนนดูแปลก ให้เทียบกับ **รหัสตรวจสอบ** ในไฟล์งานที่ส่งของนักเรียน
- ข้อมูลนักเรียน (ชื่อ ห้อง คะแนน) เก็บอยู่ใน Google Drive ของคุณเท่านั้น
- ถ้ารหัสครูรั่ว ให้เรียกใช้ฟังก์ชัน **`resetTeacherKey`** เพื่อสร้างรหัสใหม่ (ดูรหัสใหม่ในบันทึกการดำเนินการ)
